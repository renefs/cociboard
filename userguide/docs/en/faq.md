# Questions and answers

**Why can't I put a recipe in a lunch slot?**
:   Its meal type is **Dinner**. Open the recipe, press **Edit** and set the meal type to
    **Both** if it suits both meals.

**Suggest didn't fill some slots.**
:   Suggest only uses recipes that fit the slot and your [household preferences](preferences.md).
    When nothing matches, it leaves the slot empty and tells you. Loosen the preferences, add
    recipes, or fill the slot yourself.

**Suggest changed a meal I had chosen!**
:   It never does: it only fills empty slots. If you didn't like the result, press **Undo** in
    the message that appears.

**Does marking a recipe as favourite make Suggest choose it more?**
:   No. Favourites are a shortcut for you to find recipes; suggestions only look at variety
    and your preferences.

**An ingredient appears twice in the shopping list.**
:   The two recipes spell it differently ("Tomate" and "Tomate maduro"). Edit one of the
    recipes so both use the same name.

**Can each person have their own plan?**
:   No. Cociboard is one shared plan for the whole household. Everything you change is seen by
    everyone using the same Cociboard.

**How many people does a recipe feed?**
:   Each recipe can say its servings. Cociboard doesn't scale quantities: ingredients are free
    text.

**I see "You're offline".**
:   Your device lost the connection to Cociboard. Keep going: your changes are sent when it is
    back. See [Without a connection](phone.md#without-a-connection).

**A message says anyone who can reach this address can see and change the plans.**
:   Cociboard has no password and you are connecting from the internet. Tell whoever installed
    it, so they can [set a password](install.md#security).

**I deleted a recipe by mistake.**
:   Deleting can't be undone from the app. If you have a [backup](backups.md) you can restore
    it, but that replaces all newer changes. Next time, prefer **Archive**.
