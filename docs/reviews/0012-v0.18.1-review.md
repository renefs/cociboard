# Review 0012 — v0.18.1 safe dependency updates (planning/review model: Opus)

Scope: the v0.18.1 working tree written by the development subagent (Sonnet), before the
commit. Gates: `make check` passes; actionlint and shellcheck report nothing.

## Why
Right after v0.18.0, Dependabot opened PRs that CI passed although two of them would break
or change the image (base image `python:3.15`, outside `requires-python <3.14`, and
`node:26`): CI ran `make check` but never built the image on PRs. A grouped npm PR mixing
majors failed `npm ci`.

## Code review
- `ci.yml` has a new `image` job, parallel to `check`: amd64 build with the gha cache and
  `scripts/smoke-test.sh`. The publish workflow calls `ci.yml`, so it now needs both jobs
  and no longer has its own smoke test.
- `scripts/smoke-test.sh` is POSIX sh, takes the engine from `CONTAINER_ENGINE`, uses a
  per-run container and volume name and always cleans up through a trap.
- Dependabot: Python base images `>=3.14` are ignored until `requires-python` allows them;
  Node majors are done by hand; npm and uv minor/patch updates are grouped, each major is
  its own PR.
- README: the architecture diagram shows every router, the auth middleware, migrations,
  and the shopping, auth and PWA parts; the ADR list covers 0001–0021; Node 22+.

## Finding (fixed in this release)
### 1. Dependabot PRs ran CI twice (low)
A Dependabot branch triggers both `push` and `pull_request`, so each PR would build the
image twice. **Fix:** `push` ignores `dependabot/**` as well as `main`.

## Verified manually
- `CONTAINER_ENGINE=podman scripts/smoke-test.sh cociboard:smoke 8770` against an image
  built from the working tree: health reports 0.18.1, `/` is 200, "Smoke test passed".
- With a `VERSION` of 9.9.9 the script fails with "/api/health does not report version
  9.9.9" and prints the logs; no container or volume is left behind in either run.

## Not verified
- The new `image` job and the Dependabot rules only take effect on GitHub after the push;
  the `versions: [">=3.14"]` ignore for Docker tags is untested until Dependabot runs.
- The arm64 image is still only built when publishing, not on PRs (QEMU is slow).
