## Findings (fixed in this release)

### 1. Icon-only header button below the touch-target size (low)
Below 480px the backup button shows only 💾 and was 39×44px. **Fix:** `.header-button`
gets `min-width: 2.75rem`, so it is now 44×44px.

## Accepted as-is
- `replace_week` accepts archived recipes so that Undo after Clear week works (ADR-0014).
  An API client could use it to place an archived recipe, but the UI never does.
- A restored archived recipe gets the restore time as `archived_at`, because the format
  only says whether a recipe is archived. Nothing shows that time yet.
- Migration 0003 adds the column only when it is missing, as 0002 does. That is harmless
  on real databases and keeps the test databases built with `create_all` working.
- Migration copies and pre-restore copies rotate separately (3 of each). So a restore can
  never remove the copy taken before a schema upgrade.
