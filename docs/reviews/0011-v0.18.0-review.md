# Review 0011 — v0.18.0 CI before publishing (planning/review model: Opus)

Scope: the v0.18.0 working tree written by the development subagent (Sonnet), before the
commit. Gates: `make check` passes; actionlint 1.7.12 reports nothing on both workflows.

## Code review
- `ci.yml` runs `make check` after `uv sync --locked` and `npm ci`, so a stale lock file
  fails too. It runs on pull requests and on pushes to other branches. For `main` and tags
  it runs only as the first job of `docker-publish.yml`, so it never runs twice.
- `publish` has `needs: check`; workflow permissions are `contents: read` and only the
  publish job gets `packages: write`. The called workflow's concurrency group differs from
  the caller's, so the two can't wait on each other.
- A release tag must equal `v$(cat VERSION)`.
- The smoke test builds an amd64 image with the shared gha cache, starts it on a throwaway
  volume, waits up to 60 s for `/api/health`, checks the version and that `/` answers 200,
  and prints the logs on failure; cleanup always runs.
- `scripts/check-version.sh` is POSIX sh (`sed -n`, `awk`, `node -p`) and now also covers
  both versions in `package-lock.json`, the `cociboard` entry in `uv.lock` and the README
  line. The subagent showed each new check failing on a deliberate mismatch.

## Verified manually
- actionlint (`uvx --from actionlint-py actionlint`): no findings.
- The smoke-test script, extracted from the workflow and run with podman against an image
  built from the working tree, passes: the first request gets an empty reply during
  start-up, the retry gets `{"status":"ok","version":"0.18.0"}`, and `/` answers 200.
- `TZ=UTC LANG=C.UTF-8 make test` passes (subagent), so the tests don't depend on the
  Mac's time zone or locale.

## Not verified
- The workflows have not run on GitHub; that happens on the next push. The `setup-uv`
  inputs (`python-version-file`, `cache-dependency-glob`) are only syntax-checked.
- Requiring the CI check before merging is a branch-protection setting on GitHub, not
  part of the repository.

## Accepted as-is
- Actions are pinned to major versions, not commit SHAs; Dependabot (github-actions, npm,
  uv, docker, weekly and grouped) keeps them current.
