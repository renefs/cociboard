# Review 0018 — v0.24.0 favourites and history (planning/review model: Opus)

Scope: the v0.24.0 working tree written by the development subagent (Sonnet), before the
commit. Gates: `make check` passes (611 pytest, 615 vitest, ruff, mypy --strict, tsc,
ESLint, version check).

## Code review
- Favourites:
  - `recipe.favourite` is NOT NULL with a server default of false. Migration 0008 is a
    small `batch_alter_table`, and it has upgrade and downgrade tests.
  - PATCH rejects `favourite: null`. The `favourite=true` list filter combines with the
    other filters.
- History is derived from the plan and never stored:
  - `history.py` holds pure functions with fixed-date tests;
  - "made" means a meal date on or before the server's today, through the `get_today`
    dependency that tests override;
  - the list endpoint reads the meal rows in one query and folds them in Python, so there
    is no N+1;
  - the `GET /{id}/history` limit is 1–50, and anything outside is a 422.
- Backups: format v6 carries `favourite`; v1–v5 restore with none.
- Frontend:
  - the star toggle is optimistic, serialized in scope `recipe-favourite` and paused
    offline;
  - a failure reverts only that recipe and shows a toast;
  - `stopPropagation` on pointer and touch down keeps the star from starting a drag or a
    select;
  - plan mutations invalidate `["recipes"]` and `["recipe-history"]` once the last change
    settles;
  - "Not made lately" is a pure, tested sort.

## Findings
- Fixed: starring a recipe did not refresh the slot candidates, so an open picker could show
  a stale star. The toggle now also invalidates `["candidates"]` once it settles.

## Accepted as-is
- The rollback of a failed toggle is covered by unit tests only.
- At 375px the meal, sort and favourites chips take four rows above the list.
- History entries in the modal are plain text, not links to their week.
- Recipes embedded in week plans and candidates carry empty history fields (documented).
- Every recipe list request reads all meal assignments: fine at household scale.
