# Review 0023 — v0.28.0 documentation review and user guide (planning/review model: Opus)

Scope: a review of the existing documentation against the code after v0.24.0–v0.27.0, and the
new user guide (`userguide/`, ADR-0030). Written directly by the Opus session (documentation,
no app code). Gates:
- `make check` passes: 621 pytest, 652 vitest, ruff, mypy --strict, tsc (incl. the
  screenshot scripts), ESLint, version check.
- `make docs` passes (`mkdocs build --strict` with link and anchor validation).
- `make docs-screenshots` passes: 34 tests, 21 pictures per language.
- `make e2e` not run: no app code or UI flow changed (only `vite.config.ts` excludes,
  `tsconfig.e2e.json` and ESLint globs).

## Documentation audit
Checked README, AGENTS.md, ROADMAP, `.env.example` and the compose files against
`config.py`, `variety.py`, `backup.py`, the source tree and the changelog.
- README ADR list missed ADR-0024, 0025 and 0028. Fixed.
- `COCIBOARD_SESSION_DAYS` was documented in the security section but missing from the
  settings table, `.env.example` and both compose files, so it could not be set in Docker.
  Added everywhere; compose defaults it to `90` because `config.py` does not treat an empty
  `session_days` as unset (unlike the backup numbers).
- The variety section said the thresholds are constants in `variety.py`; since v0.23.0 they
  are household settings with those defaults. Reworded.
- The ghcr tag example (`0.8.0`, `0.8`) and the `.env.example` tag example were old; now
  `0.27.0` / generic.
- Project structure missed `features/auth`, `pwa/`, `sw/`, `offline/`, `docs/reviews/`, and
  named `CLAUDE.md` as the conventions file (it is `AGENTS.md`). Fixed; AGENTS.md's layout
  listed only three feature folders. Fixed.
- Everything else matched: backup format 6, API tables, offline limits, seed command, CI.

## User guide
- Site: MkDocs Material + mkdocs-static-i18n, English and Spanish, eleven user pages plus an
  installation page. Spanish uses the exact labels of `es.ts` (checked: Sugerir, Copiar semana
  anterior, Vaciar semana, Comemos fuera, Buena opción, Siempre en casa, Hay que comprar, Copia,
  Preferencias del hogar…). Every feature claim was checked against the README and the code.
- Screenshots come from the real build with the starter recipes. Checked each picture: the
  mouse drag needed the same move pattern as `e2e/helpers.ts` (a single straight move only
  selected text); tall dialogs use a taller viewport so steps and history fit; Spanish slot
  names need the app language code (`es`), not the Intl locale.
- Browser check of the built site at 1440 px (light and dark) and 375 px: navigation,
  language switcher, phone pictures side by side, no horizontal scroll.
