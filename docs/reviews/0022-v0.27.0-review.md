# Review 0022 — v0.27.0 seed recipes with steps and servings (planning/review model: Opus)

Scope: the v0.27.0 working tree written by the development subagent (Sonnet), before the
commit. Gates:
- `make check` passes: 621 pytest, 652 vitest, ruff, mypy --strict, tsc, ESLint, version
  check.
- `make e2e` passes: 58 tests.

## Code review
- Content:
  - all 33 seed recipes have servings (2, 4 or 6) and 4–8 steps in Spain Spanish;
  - the steps are imperative and give heat levels and times that fit `prep_minutes`;
  - two recipes gained "Aceite de oliva" because their steps fry in it;
  - spot-checked Lentejas, Tortilla, Paella, Cocido and Gazpacho: realistic and consistent
    with the ingredient lists.
- Fill rule:
  - `should_fill_content` is pure and tested: fill only when there are no steps and the
    servings are null;
  - names are matched case-insensitively, and archived recipes are filled too;
  - startup is unchanged (`seed_if_empty` only on an empty database). Existing users run
    `make seed` or the container command.
- `seed_recipes` returns `SeedResult(inserted, filled)`; `test_archive.py` is adapted to it.
- `seed.py` has a ruff E501 per-file ignore, so each step stays on one readable line.

## Verified manually
Podman, with images built from the `v0.26.0` tag and the working tree:
- a database seeded by 0.26.0 has 33 recipes and none with steps;
- in 0.26.0, Lentejas got servings 3 by hand and Paella was archived;
- after upgrading to 0.27.0 nothing changes on startup;
- `podman exec --user 1000:1000 <container> python -m cociboard.seed` prints "Seeded 0 new
  recipe(s), filled steps for 32 existing recipe(s)", and a second run fills 0;
- Lentejas keeps servings 3 and no steps (user edit respected), and the archived Paella is
  filled (servings 4, 7 steps).

## Findings
None.

## Accepted as-is
- The descriptions stay in English while the rest of the seed content is Spanish. This is
  pre-existing and out of scope.
- A user who set only the servings of a seed recipe does not get its steps. This is
  intended: anything the user set is left alone.
- Not checked in the browser: the details modal already shows steps and servings
  (v0.21.0), and this release only adds data.
