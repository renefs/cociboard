# Review 0025 — v0.29.0 visual refresh, phase 1 (planning/review model: Opus)

Scope: the v0.29.0 working tree written by the development subagent (Sonnet), before the
commit. The owner approved the mockups of a three-phase refresh; this is phase 1: tokens with
a dark theme, the Figtree font, line icons for the chrome and a settings menu in the header
(ADR-0031). Gates:
- `make check` passes (vitest 688 tests in 61 files, pytest 622, ruff, mypy --strict, tsc,
  ESLint, version check).
- `make e2e` passes, including the new axe scans of the open settings panel and of the Week
  and Recipes views in the dark scheme.
- `make docs-screenshots` passes; all pictures regenerated.

## Review
- Tokens: no colour literal is left in the screen stylesheets; the dark block is
  `@media screen and (prefers-color-scheme: dark)`, so printing stays light. Old token names
  survive as aliases, which kept the component CSS diff small. `contrast.test.ts` now parses
  `tokens.css` for both themes instead of repeating hexes, so it cannot drift from the CSS.
- The "quick" property colour moved from #8a6a00 to #7d5f00: the old value was 4.38:1 on the
  new primary tint. Meal-type badges get a lighter `darkColor`.
- `SettingsMenu` follows the share menu's disclosure pattern (not `role="menu"`, because it
  holds the language button group): Escape and outside clicks close it, focus moves into the
  panel and back to the trigger, tabbing out closes it, and opening a dialog returns focus to
  the trigger first so the dialog restores it there. Logout logic moved into `useLogout` and
  is unchanged. Item accessible names are unchanged, so only an `openSettings` step was added
  to the E2E specs.
- Fix made in review: the Spanish backup item said "Copia", a short label chosen for the old
  crowded header. In a menu it reads as "copy", so it is now "Copia de seguridad"; the
  Spanish guide and screenshots follow.
- README: the header mentions (log out, preferences, backup, language) now point to the
  settings menu.

## Verified manually

(inside the viewport on the phone, no horizontal scroll), focus landing on the first item,

## Left for later phases
